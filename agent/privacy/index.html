Privacy policy

Agent · effective 23 October 2026

Who runs Agent

Agent is a personal tool run by Erick Boumard-Ermine for his own use. It is not offered to the public. Questions: toupixv7@gmail.com.

What Google data it accesses

Only Google Calendar data of the Google account that authorizes it, through two permissions:

  • calendar.events.owned — to create, update and delete the suggestion events on the calendars that account owns;
  • calendar.events.readonly — to read the events of the calendars that account can see: their times, titles, places and descriptions, and the answers given to Agent's invitations.

Agent does not access email, contacts, files or any other Google service.

How it uses that data

  • to suggest activities at times when the owner is free;
  • to send those suggestions as calendar invitations and read the answers;
  • to learn, from those answers, which suggestions the owner likes.

Where it is stored, and who sees it

Calendar data and the authorization token are kept on a private server controlled by the owner. To judge whether a suggestion fits, Agent may send the details it needs to an AI model service used by the owner. The data is not sold, not used for advertising, and not shared with anyone else.

Retention and deletion

Data is kept while the owner uses Agent. Access can be withdrawn at any time from the Google account's third-party connections page; Agent then stops reading and writing at once. To have stored data deleted, write to the address above.

Google API Services User Data Policy

Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
